# VenueTuner — P1/M1-parity features (record)

Goal: close the workflow gaps with the L-Acoustics P1 + M1 platform for any sound system
(see the P1 research in the session of 2026-10-09). Never use L-Acoustics names, branding or presets.

- [x] **Measurement matrix** — groups (outputs played together) × mic positions; one mic is enough
  (move it, press ▶); sequenced capture per group with stable-arrival wait, 3 s averaging, quality =
  mean coherence over the group's own band (≥ 0.8), one automatic retry, ✓/✗ grid, per-group
  average across positions feeding Auto-EQ. Tests: quality function, state round-trip, group
  cleanup on output removal; BlackHole end-to-end (heard group ✓ 100 %, unheard group ✗ after retry).
- [x] **Speaker preset library** — speaker fields only (XO, PEQ, AP, limiter, polarity, trim, FIR with
  embedded coefficients) vs venue fields (delay, routing, channel, mute) untouched; save / apply to
  linked outputs / export / import (`.vtpreset`), undoable. Tests incl. FIR surviving deletion of its
  original file and export→import equivalence.
- [x] **Air-absorption compensation** — ISO 9613-1 α(f, T, RH, p) (matches the standard's table within
  3 %); per-output distance; high shelf fitted to d·(α_now − α_ref), cap −6…+9 dB, own IIR slot
  (kIirAir = 28). Tests: ISO table, typical evening change within 0.4 dB, cap holds; end-to-end
  through the engine within 0.4 dB at 4/8/12 kHz.
- [ ] **Multiple simultaneous measurement mics** (engine: one analyzer per mic input).
- [ ] **Dedicated box** (Milestone 4): headless Linux/Mac mini engine, LAN control with trusted controllers.
