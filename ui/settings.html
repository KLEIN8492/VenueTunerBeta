Audio interface

Changing the interface mutes all outputs until you unmute them in the Live window.

Where the latency comes from

Inputs

Create only the inputs you use, name them, and pick the interface channel each one comes in on. Program = sound to process (console…). Mic = measurement mic, never sent to the speakers. Loopback = cabled reference.

Outputs

Create one output per speaker feed, pick the interface channel it goes out on, and choose which inputs feed it. Each output gets its own processing in the Live window.

Interface latency

The internal loopback compensates the latency the driver reports. For best precision, connect an output to an input with a cable and calibrate once per interface / rate / buffer.
